# Phrases

Each phrase is a `##` heading. Fields are `- key: value`. The fenced block is
the dialogue, newlines preserved, speaker labels in bare uppercase.

A dialogue must read like a real exchange. See CLAUDE.md rule 4.

## Cześć
- meaning: Hi / bye (informal)
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Both greeting and farewell. Informal only.

```
MAYA: Cześć! Jak się masz?
JA: Cześć! Dobrze, dziękuję.
MAYA: To dobrze!
```

## Dzień dobry
- meaning: Good morning / good day
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Formal, used until early evening.

```
JA: Dzień dobry!
PANI: Dzień dobry. W czym mogę pomóc?
JA: Chleb, proszę.
```

## Dobranoc
- meaning: Good night
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Parting only, never a greeting.

```
MAMA: Już późno. Idź spać.
JA: Dobranoc, mamo.
MAMA: Dobranoc! Śpij dobrze.
```

## Dziękuję
- meaning: Thank you
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Literally "I thank".

```
TY: Proszę, to dla ciebie.
JA: Dziękuję!
TY: Nie ma za co.
```

## Proszę
- meaning: Please / here you are / you are welcome
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Also answers Dziękuję.

```
JA: Chleb, proszę.
PANI: Proszę.
JA: Dziękuję bardzo!
```

## Jak się masz?
- meaning: How are you?
- conf: 3
- source: duolingo
- learned_on: 2026-10-12
- note: Informal. Contains masz, already a known form.

```
JA: Cześć Maya! Jak się masz?
MAYA: Dobrze, a ty?
JA: Też dobrze, dziękuję.
```

## Do widzenia
- meaning: Goodbye
- conf: 2
- source: duolingo
- learned_on: 2026-10-12
- note: widzenia is the genitive of widzenie, used only in this phrase.

```
JA: Dziękuję bardzo!
PANI: Proszę. Do widzenia.
JA: Do widzenia!
```

## Nie wiem
- meaning: I do not know
- conf: 2
- source: duolingo
- learned_on: 2026-10-12
- note: wiedzieć, first person singular.

```
MAYA: Gdzie jest mama?
JA: Nie wiem.
MAYA: Może w domu?
```

## Dobry wieczór
- meaning: Good evening
- conf: 1
- source: duolingo
- learned_on: 2026-10-12
- note: Evening greeting. Dobranoc is for leaving.

```
JA: Dobry wieczór!
PANI: Dobry wieczór. Stolik dla dwóch?
JA: Tak, proszę.
```

## Mam na imię
- meaning: My name is
- conf: 1
- source: duolingo
- learned_on: 2026-10-12
- note: Literally "I have for a name". Contains mam.

```
MAYA: Cześć! Jak się nazywasz?
JA: Mam na imię Matt. A ty?
MAYA: Maya. Miło mi!
```

## Miło mi
- meaning: Nice to meet you
- conf: 1
- source: duolingo
- learned_on: 2026-10-12
- note: Short for Miło mi cię poznać.

```
MAYA: To jest Tomek.
JA: Miło mi.
TOMEK: Miło mi bardzo!
```

## po polsku
- meaning: in Polish
- conf: 2
- source: duolingo
- learned_on: 2026-10-13
- note: polsku is an archaic dative of polski, kept alive only by this phrase.

```
MAYA: Cześć!
JA: Cześć! Mówisz po polsku?
MAYA: Tak, mówię po polsku.
JA: Bardzo dobrze!
```

## po angielsku
- meaning: in English
- conf: 2
- source: duolingo
- learned_on: 2026-10-13
- note: angielsku is an archaic dative of angielski, kept alive only by this phrase.

```
MAYA: Dzień dobry!
JA: Dzień dobry. Mówisz po angielsku?
MAYA: Tak, mówię po angielsku.
JA: Dziękuję!
```
